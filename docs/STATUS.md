# Public implementation status

This package is a fixture-only development preview. It is not a general desktop
control product or a certified production release.

The package contains Swift contracts, session and execution policy, native macOS
adapters, a Swift client, MCP transport, provider adapters, an agent loop, a
native control application and a fixture. Public evidence is in [evidence](evidence/README.md).

Historical evidence is scoped to the recorded binary and test environment.
Sanitized logs are historical records, not proof that the current source passed
native or provider acceptance. A source rebuild does not renew live acceptance.

Production publisher identity, signed distribution, supported OS/hardware
coverage, general application control and complete interruption acceptance
require their own validation. No broader support is claimed here.
