# Public archive privacy

This repository's published history uses synthetic contributor identities and
example filesystem paths. Private host plans, integration records and build
logs are omitted. The integration example is application independent.

Historical evidence has been sanitized. Its field values and bytes can differ
from the original records; it does not establish acceptance of the current
checkout. Original source manifests are withheld. Regenerate manifests locally
when validating a new build, and keep actual credentials outside the repository.

The logo is published without EXIF or text metadata. Its image data is preserved.

Use a non-personal Git author email for new commits. Inspect logs and image
metadata before publishing them. Ignore rules do not erase files already in Git
history. After a history rewrite, start from a fresh clone rather than merging
old history back into the public branches.
